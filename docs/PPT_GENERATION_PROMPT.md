# PPT 제작 기준 프롬프트 기록

이 파일은 공학논문 연구 발표 PPT를 만들 때 사용한 요구사항과 수정 프롬프트를 정리한 기록이다.
PPT 내용을 다시 수정하거나 다른 AI에게 제작을 맡길 때 참고할 수 있다.

## 1차 제작 프롬프트

```text
나는 공학논문 연구 발표 PPT를 제작하려고 한다.

논문 주제는 다음과 같다.

“관절 위치 정보 기반 운동 동작 분류 및 성능 및 오분류 패턴 비교 분석”

연구 내용은 AI-Hub 피트니스 자세 이미지 데이터셋의 3D 관절 좌표 JSON을 이용해
맨몸운동 17개 동작을 분류하고,
SVM, XGBoost, GNN, Transformer 모델의 성능과 오분류 패턴을 비교한 것이다.

발표 시간은 12분이고, 질의응답은 2분이다.

PPT 디자인 조건은 다음과 같다.
- 흰 배경
- 검정색 큰 제목
- 빨간색 포인트 컬러
- 넓은 여백
- 한 슬라이드에 하나의 핵심 메시지
- 긴 논문 문단을 그대로 넣지 않기
- 표는 너무 크게 넣지 말고 요약해서 사용
- 그래프는 가능한 크게 넣기
- 수식은 최소화하고, 필요하면 핵심 수식만 사용
- 발표자가 말로 설명하고, PPT는 핵심만 보여주는 방식으로 구성

반드시 반영할 정보:
- 데이터셋: AI-Hub 피트니스 자세 이미지 데이터셋
- 사용 파일: -3d.json
- 샘플 단위: JSON 파일 1개 = 운동 수행 샘플 1개
- 평가 단위: 프레임 단위가 아니라 샘플 단위
- 유효 샘플 수: 16,408개
- 운동 라벨: 맨몸운동 17개
- 관절 수: 24개
- 좌표: x, y, z
- 특징: 평균, 표준편차, 최솟값, 최댓값, 움직임 범위, 시작-종료 변화량, 평균 이동량
- 모델: SVM, XGBoost, GNN, Transformer
- 데이터 분할: Train / Validation / Test
- 반복 실험 seed: 42, 7, 21, 100, 2026
- 주요 지표: Accuracy, Macro-F1, Weighted-F1, Confusion Matrix
- 주요 비교 지표: Macro-F1

최종 성능:
- SVM Macro-F1: 0.9044
- XGBoost Macro-F1: 0.9006
- Transformer Macro-F1: 0.8770
- GNN Macro-F1: 0.8462

핵심 결과 해석:
- SVM과 XGBoost가 가장 안정적인 성능을 보였다.
- 오분류는 무작위가 아니라 자세와 관절 움직임이 유사한 운동 사이에서 집중되었다.
- 푸시업과 니푸쉬업, 크런치 계열, 런지 계열에서 혼동이 많았다.
- 버피 테스트는 전신 움직임이 뚜렷해 높은 성능을 보였다.
- 단, 이 결과는 AI-Hub 데이터셋 조건에서의 성능이며, 직접 촬영한 웹캠/MediaPipe 데이터에 바로 일반화된다고 단정할 수 없다.

주의할 점:
- LSTM, ST-GCN을 사용한 것으로 쓰면 안 된다.
- 프레임 하나를 샘플로 학습했다고 쓰면 안 된다.
- 버피 테스트 1.0000을 “완벽한 모델”이라고 해석하면 안 된다.
- AI-Hub 데이터셋 결과를 실제 모든 환경에 일반화하면 안 된다.
- 논문 문장을 그대로 복사하지 말고 발표용 문장으로 줄여야 한다.
```

## 2차 수정 프롬프트

```text
참고 Google Slides 링크 2개를 논문 발표 PPT의 구성 참고 자료로 사용한다.
템플릿 양식은 기존의 흰 배경, 검정 제목, 빨간 포인트 컬러, 넓은 여백 스타일을 유지한다.
페이지 수는 고정하지 않는다.

내 논문의 내용과 실험 결과가 모두 적절하게 포함되어야 한다.
“운동 동작 분류 및 성능 및 오분류 패턴 비교”라는 발표 목적에 맞게
핵심 실험 결과, methodology 속 수식, 모델별 방법론, 데이터 처리 과정, 오분류 분석,
주요 지표 검증, 자세 그룹별 분석, 한계점과 향후 연구를 포함한다.

슬라이드 비율은 1920x1080 해상도에 맞는 16:9 와이드 비율로 수정한다.
```

## 최종 제작 반영 사항

- 최종 PPT는 16:9 와이드 비율로 설정하였다.
- 슬라이드 크기: 13.333 × 7.5 inch, PowerPoint 내보내기 기준 1920×1080에 대응한다.
- 총 24장 구성으로 재작성하였다.
- 논문 발표 흐름은 `연구 배경 → 연구 목적 → 데이터셋 → 전처리 → 특징 수식 → 모델 방법론 → 평가 지표 → 성능 비교 → 오분류 분석 → 지표 검증 → 자세 그룹 분석 → 한계 및 결론` 순서로 정리하였다.
- 기존 템플릿의 흰 배경, 검정 제목, 빨간 포인트 컬러를 유지하였다.
- 실험 결과 그림과 표는 `outputs_fitness_pose/thesis_tables_figures`의 최종 결과물을 사용하였다.
